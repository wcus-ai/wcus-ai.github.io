Agent Skills

Portable bundles that teach AI coding assistants how to build WordPress correctly.

AI coding assistants are powerful, but they often generate outdated WordPress patterns, miss critical security considerations, and skip block deprecations.

Agent Skills solve this by giving AI assistants — Claude, Copilot, Codex, Cursor, and others — expert-level WordPress knowledge in a portable format they can actually use. Each skill is a self-contained folder with instructions, references, and validation scripts. Install them per-project so the whole team benefits, or globally for personal use across every repo.
