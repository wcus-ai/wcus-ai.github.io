MCP Adapter

Connects WordPress abilities to external AI tools over the Model Context Protocol.

The Model Context Protocol (MCP) is the open standard for letting AI tools talk to external systems. The MCP Adapter exposes WordPress abilities — registered via the Abilities API — to any MCP-compatible AI tool, so Claude Desktop, Cursor, or any other MCP client can interact with your WordPress site in a standardized way.
