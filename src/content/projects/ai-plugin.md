The (<a href="https://make.wordpress.org/core/2022/09/11/canonical-plugins-revisited/" target="_blank" rel="noopener noreferrer" data-track-event="click_outbound" data-track-project="ai-plugin" data-track-target="canonical-plugins-post">canonical</a>) AI Plugin provides end-users with a set of opt-in, AI-powered features and experimental functionality.

The plugin serves as a reference implementation for developers, agencies, and hosts looking to build or extend AI-powered workflows, the teams other projects, including the <a href="../ai-client" data-track-event="click_internal" data-track-project="ai-plugin" data-track-target="ai-client">AI Client</a>, <a href="../mcp-adapter" data-track-event="click_internal" data-track-project="ai-plugin" data-track-target="mcp-adapter">MCP Adapter</a>, and the <a href="../abilities-api" data-track-event="click_internal" data-track-project="ai-plugin" data-track-target="abilities-api">Abilities API</a>.

There are currently 22 AI features and experiments available in the plugin, with more in development.
